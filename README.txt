GITHUB PAGES DEPLOYMENT
1. Create a new public GitHub repository, e.g. deepak-sparshita-engagement.
2. Upload index.html, style.css, script.js, and the complete assets folder to the
   repository root. Do not upload only the ZIP file.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose “Deploy from a branch”.
5. Select branch “main” and folder “/(root)”, then Save.
6. Wait for GitHub Pages to publish the site. Your URL will be:
   https://YOUR-USERNAME.github.io/deepak-sparshita-engagement/

WHATSAPP LINK PREVIEW
The assets/invitation-preview.jpg file is a starter preview image. Once the site
is published, social platforms may cache link previews. The og:image path is
relative in this starter. For reliable Open Graph previews, update the og:image
in index.html to the absolute published URL:
https://YOUR-USERNAME.github.io/deepak-sparshita-engagement/assets/invitation-preview.jpg

Then test the link using a social sharing debugger or send it in a test chat.
Some platforms cache old previews for a while.
